# Security

This project supports research and simulation. It provides no guarantee of
airworthiness or flight safety. Before use on a physical aircraft,
independently verify the flight envelope, failsafes, geofence, link-loss
behavior, command limits, camera calibration, and ArduPilot version.

Enable GitHub Private Vulnerability Reporting for sensitive findings.
Public issues must not contain actual vehicle locations, credentials,
telemetry, keys, or operational details.
