# Security

This project is intended for research and simulation. It provides no guarantee
of airworthiness or safety. Before applying the code to an aircraft,
independently validate the flight envelope, failsafes, geofence, link-loss
behavior, command limits, camera calibration, and the ArduPilot version used.

Public vulnerability reports must not include actual vehicle locations,
credentials, telemetry, keys, or operational details. Submit sensitive reports
through GitHub **Private Vulnerability Reporting**.

The experimental code in `future_research/` is not a supported release for
production or real flight.
