# Güvenlik

Bu proje araştırma ve simülasyon amaçlıdır; uçuşa elverişlilik veya güvenlik
garantisi vermez. Kod gerçek bir araca uygulanmadan önce uçuş zarfı, failsafe,
geofence, bağlantı kaybı, komut sınırları, kamera kalibrasyonu ve kullanılan
ArduPilot sürümü bağımsız olarak doğrulanmalıdır.

Güvenlik açığı bildirimleri public issue içinde gerçek araç konumu, erişim
bilgisi, telemetri, anahtar veya operasyon ayrıntısı içermemelidir. Hassas
bildirimler GitHub **Private Vulnerability Reporting** kanalı üzerinden
gönderilmelidir.

Deneysel `future_research/` kodu üretim veya gerçek uçuş için desteklenen bir
sürüm değildir.
