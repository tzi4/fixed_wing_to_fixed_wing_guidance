# Contributing

Submit contributions as small, explainable commits with reproducible test notes.
Clearly distinguish behavior validated in real flight from SITL or experimental
results.

A pull request should describe:

- The guidance behavior being changed and its safety limits.
- The ArduPilot, Gazebo, and ROS versions used.
- The test or simulation commands executed.
- The source and redistribution license of any added data, models, or code.
- Whether personal and operational information has been removed from any
  included real-flight data.

Do not commit secrets, model weights, raw flight logs, video, facility
coordinates, or third-party assets with uncertain redistribution permission.
