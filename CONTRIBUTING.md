# Katkı rehberi

Katkılar küçük, açıklanabilir commit'ler ve yeniden üretilebilir test notlarıyla
gönderilmelidir. Gerçek uçuşta doğrulanmış davranış ile yalnız SITL/deney
sonuçları açıkça ayrılmalıdır.

Bir pull request en az şunları belirtmelidir:

- değişen güdüm davranışı ve güvenlik sınırları;
- kullanılan ArduPilot/Gazebo/ROS sürümleri;
- çalıştırılan test veya simülasyon komutları;
- eklenen veri, model veya kodun kaynağı ve dağıtım lisansı;
- gerçek uçuş verisi içeriyorsa kişisel/operasyonel verilerin temizlendiği.

Secret, model ağırlığı, ham uçuş logu, video, tesis koordinatı veya yeniden
dağıtım izni belirsiz üçüncü taraf varlığı commit etmeyin.
